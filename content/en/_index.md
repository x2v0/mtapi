# mtapi

**Android HTTP bridge**: 60+ API endpoints via HTTP. Sensors, camera, network, debug overlay, browser. **No root / Shizuku / Termux**. **< 2 MB**. Open source.

{{< hint info >}}
**v2.13.2** · MIT · [GitHub](https://github.com/x2v0/mtapi) · [Releases](https://github.com/x2v0/mtapi/releases/latest) · [Demo](/mtapi/demo/)
{{< /hint >}}

## Quick start

    # 1. Install APK (Releases → latest)
    # 2. Open mtapi → WebView → server on :7788
    curl http://127.0.0.1:7788/battery?token=YOUR_TOKEN
